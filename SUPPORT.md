# Support

## Using the software

Use GitHub Discussions or a public issue for installation problems, documentation gaps, reproducible bugs, and feature proposals that contain no sensitive workplace information.

## Workplace help

This repository is not a confidential case-management channel. Do not post employer names, coworker identities, organizing plans, or intake messages in GitHub issues.

Use the public guides for orientation. If the deployed encrypted intake is available and you can safely use a personal device, use the organizer-contact path on `https://unionize.software` for human support.

## Security

Follow `SECURITY.md` for vulnerabilities or accidental exposure of sensitive information.
